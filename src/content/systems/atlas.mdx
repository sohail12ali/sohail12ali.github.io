## The problem
The platform was a large ecosystem built up over years: several repositories, modern .NET MAUI and Blazor next to legacy WinForms and WCF, and a schema too large for anyone to hold in their head. Every change risked side effects nobody could see.

## What I built
- **A full-SDLC skill library.** Procedural skills cover requirements, implementation, automated verification and release staging. Teams run them as slash commands.
- **A ticket-centric knowledge vault.** Every ticket gets its own environment: context, decisions, progress and proof.
- **Graph RAG over the schemas.** Before anyone touches the database, agents trace the blast radius of a change and show what it would affect.
- **Three IDEs, one voice.** Prompts and skills are standardized across Cursor, Claude Code and Copilot. MCP connects the agents to the issue tracker and the databases.
- **Evidence-before-done.** Automated E2E pipelines use Appium for regression and Maestro for fast, UI-accurate mobile flows. Nothing is "done" without a passing run.

## Human in the loop
Agents propose; humans approve. Clear safety boundaries decide what an agent may do alone and what needs sign-off.

## Enablement
I rolled the harness out through hands-on workshops, so cross-functional teams could use the slash commands and ship features faster, and so it wasn't just a tool one person used.
